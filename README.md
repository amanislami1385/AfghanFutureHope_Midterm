## Project Overview

This is my Midterm Project for WEB Technologies 1.

I created a two-page responsive website for **Afghan Future Hope**.

The main idea of the project is to connect Afghan young people with education, scholarships, digital skills, mentorship, and international opportunities.

I wanted to create a website that is simple, professional, meaningful, and easy to use on different devices.

---

## Pages

The project contains two main pages:

### 1. Home Page

The Home page introduces Afghan Future Hope and explains its purpose.

It includes:

- Hero section
- About section
- Impact section
- Programs section
- Education and technology information
- Path to Opportunity
- Call-to-action section
- Footer

### 2. Opportunities Page

The Opportunities page focuses on educational and professional opportunities.

It includes:

- Opportunities hero section
- Scholarship card
- Online learning card
- International programs card
- Opportunity comparison table
- Application preparation section
- Bootstrap accordion
- Contact/interest form
- Mobile-only message
- Footer

## Responsive Design

The website was designed and tested for different screen sizes.

### Mobile

Approximately **375px**

The content changes into a more vertical layout so that it is easy to read on a phone.

### Tablet

Approximately **768px**

The layout begins to use multiple columns and larger spacing.

### Desktop

Approximately **1280px**

More content can be displayed next to each other and the website uses the available screen space.

---

## Design Concept

The main visual style uses **dark navy, gold, white, and light gray**.

Navy gives the website a professional and trustworthy feeling.

Gold is used for important buttons, numbers, labels, and highlights.

I also added photographs related to students, education, computers, and learning.

The combination of the colors, photographs, cards, and typography creates a modern educational organization style.

## Main Features

### Responsive Navigation

The navigation bar is shared between both pages.

On desktop, the links are displayed horizontally.

On mobile, Bootstrap changes the navigation into a collapsible menu.

### Program Cards

The Home page contains four main program areas:

1. Education
2. Digital Skills
3. Mentorship
4. Global Opportunities

### Opportunity Cards

The Opportunities page contains cards for:

1. Scholarships
2. Online Learning
3. International Programs

### Table

A comparison table is included to organize different types of opportunities and their requirements.

### Form

The Opportunities page contains a form where users can enter:

- Name
- Email
- Main Interest
- Message

### Accordion

A Bootstrap accordion provides information about:

- Preparing a CV
- Writing a motivation letter
- Checking requirements
